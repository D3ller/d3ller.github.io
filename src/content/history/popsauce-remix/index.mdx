A remake of the PopSauce quiz game, built as a university project (SAE 401). Players join rooms and answer questions in real time, sorted by theme.

- **Front end**: Vue with SCSS, including an admin area to manage themes and users, and to review questions suggested by players.
- **Game server**: Express and Socket.IO for the rooms.
- **API**: Symfony with API Platform, Doctrine and JWT authentication, running in Docker.
