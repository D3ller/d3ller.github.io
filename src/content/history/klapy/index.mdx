Klapy is a rewrite of Blapy in TypeScript, without jQuery. Blapy turns a classic server-rendered website, built with PHP or a CMS, into a single-page app by updating only the blocks that change instead of reloading the whole page, while keeping normal URLs for SEO.

The new build is a single bundle built with Vite. Animations and WebSocket updates ship as optional plugins that the core detects on its own. It is tested with Vitest and Playwright.
